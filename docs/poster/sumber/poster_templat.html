Sistem pendukung keputusan untuk posko siber satuan. Mesin mempercepat, manusia memutuskan.

Perisai pertahanan (Defensive Shield) luring yang mendeteksi, mencegah, dan membantu merespons: memutus dalam ±1,2 detik tanpa menghapus barang bukti. Jaringan kantor (IT) dan kendali fasilitas (OT) dalam satu layar.

Identify

Protect

PR
  • Akses posko berlapis (PBKDF2, token kedaluwarsa, CSP) BERJALAN
  • Kepatuhan backup < 24 jam dan uji pulih BERJALAN

{{i:eye}}

Detect

melihat ancaman lebih awal

DE
  • AI lokal (±10 ms) + aturan login gagal dan pindai port BERJALAN
  • Triase: Selesai atau Positif Palsu (False Positive), beralasan BERJALAN
  • Sensor jaringan nyata (Wazuh, Suricata, Zeek) PETA JALAN
{{i:siren}}

Respond

menanggapi insiden

RS
  • Bukti dulu → isolasi ±1,2 dtk → LAPSIT BERJALAN
  • Pemutusan perangkat sasaran SIMULASI
  • Respons bertingkat per aset; LAPSIT berjenjang PETA JALAN
{{i:life-buoy}}

Recover

kembali normal tanpa merusak bukti

RC
  • Pulihkan terkunci sampai SHA-256 cocok ulang BERJALAN
  • Isolasi darurat wajib beralasan; bukti susulan sebelum pulih BERJALAN
  • Semua langkah tercatat di buku berantai HMAC BERJALAN

{{i:lock}}Posko ini sendiri dijaga berlapisBERJALAN

  • Kata sandi PBKDF2-SHA256 200.000 putaran; login dibatasi 5 kali per menit
  • Token acak yang kedaluwarsa; server hanya menyimpan hash-nya
  • Kiriman di atas 16 KB ditolak; kolom tak dikenal ditolak
  • Kebijakan keamanan konten ketat; tanpa CDN atau skrip luar
  • Log audit dan Buku Rantai Bukti berantai HMAC: diubah = ketahuan
  • Paket pasang luring bersidik jari SHA-256 untuk jaringan air-gapped

{{i:info}}Yang kami akui terus terang

  • Data latihan sintetis (alamat RFC 5737); pemutusan perangkat masih simulasi
  • Belum ada verifikasi dua langkah dan uji penetrasi independen
  • Saat tersambung ke perangkat nyata, wajib: brankas kredensial, hak minimum per playbook, playbook bertanda tangan, persetujuan dua orang
  • Asisten narasi LLM lokal masih peta jalan
